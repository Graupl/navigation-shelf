# Graupl Navigation Shelf

Navigation Shelf adds a collapsible navigation region to [Graupl](https://github.com/Graupl/graupl). It is part of [Accessible Ecosystem](https://github.com/Accessible-Ecosystem).

Install the beta with `npm install @graupl/navigation-shelf@beta`. Import the component from `@graupl/navigation-shelf/navigation-shelf` or the generator from `@graupl/navigation-shelf/navigation-shelf/generator`.

To compile the styles, enable Sass's Node package importer and use `@use "pkg:@graupl/navigation-shelf";`. Compiled CSS is available at `dist/css/navigation-shelf.css`.

See the [contribution guidelines](.github/CONTRIBUTING.md) for build instructions.
